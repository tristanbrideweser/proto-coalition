ProtoPNet: dissect image to find prototypical parts, and combine evidence to make classification 
- convolutional layers to compress images
- prototype layer to identify key distinguishing features
- max pool to determine importance in features
- fully connected layers to connect similarity scores to output logits for classifications 

ProtoConcepts: deep learning + case-based reasoning using prototypical parts 

ProtoX: prototype-bases post-hoc policy explainer
- use imitation learning via BC to train a policy
- aggregate across timesteps (correlation in nearby frames)
